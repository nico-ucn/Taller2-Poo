# Taller2-Poo
Integrante: Nicolas Maximo Lucero Bruna

Estructura del Proyecto 
`Main.java`: Clase principal que contiene el menú interactivo, la lectura/escritura de archivos `.txt` y la lógica de cálculo de métricas.
`Consumo.java`: Clase padre abstracta/base que define los atributos comunes (consumidor, fecha).
`Choripan.java`: Clase hija que hereda de Consumo, agrega largo y ancho, y calcula sus propias calorías.
`Terremoto.java`: Clase hija que hereda de Consumo, agrega litros, y calcula sus propias calorías.

instrucciones de ejecucion
1. descargar el repositorio en tu equipo local.
2. Importar el proyecto en el IDE Eclipse.
3. Asegurarse de que los archivos `Participantes.txt` y `Consumido.txt` se encuentren en la raíz del proyecto
4. Ejecutar la clase `Main.java` para iniciar el menú en la consola.
